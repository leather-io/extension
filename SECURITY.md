# Security Policy

## Reporting a Vulnerability

We consider the security of Leather a top priority. If you discover a security vulnerability, please report it responsibly.

### How to Report

Please use one of the following methods to report security vulnerabilities:

1. **HackerOne Program** (Preferred): Report the security issue to our [HackerOne program](https://hackerone.com/leather_wallet)

2. **Email**: Report the security issue directly at [security@leather.io](mailto:security@leather.io)

> **Note**: These channels are strictly for reporting security vulnerabilities. For support queries, please contact [contact@leather.io](mailto:contact@leather.io).

### What to Include

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact of the vulnerability
- Any suggested fixes (optional)

### Response Timeline

- We aim to acknowledge receipt of your report within **48 hours**
- We will provide a more detailed response within **7 days**, indicating the next steps
- We will keep you informed of the progress toward a fix

### Recognition

Your efforts to responsibly disclose your findings are sincerely appreciated and will be taken into account to acknowledge your contributions.

## Security Audit

In Q1 2021, Leather partnered with [Least Authority](https://leastauthority.com/), a leading security consultancy with experience in the crypto space, to audit Leather. On April 29th 2021, after addressing the major concerns described in the initial findings, a final report was delivered.

[Download and read the full audit report](https://github.com/leather-io/extension/blob/main/public/docs/least-authority-security-audit-report.pdf)

## Security Best Practices for Users

- Always download Leather from official sources ([Chrome Web Store](https://chromewebstore.google.com/detail/leather/ldinpeekobnhjjdofggfgjlcehhmanlj) or build from source)
- Never share your secret key or password with anyone
- Be cautious of phishing attempts and fake websites
- Keep your browser and extension up to date
